# Code of conduct

Be kind, be useful, assume good faith.

* Welcome newcomers and answer questions patiently.
* Critique code and ideas, not people.
* No harassment, discrimination, personal attacks or publishing other people's private information.
* Keep discussion on topic and in public, so everyone can learn from it.

Maintainers may edit, hide or remove comments, issues and contributions that break these rules, and may block people who repeatedly do. To report a problem, use a private security advisory on the repository.
